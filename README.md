# my_portfolio

Modern portfolio built with **Next.js + TypeScript + Tailwind CSS + Framer Motion**.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production checks

```bash
npm run lint
npm run build
```

## Deployment

GitHub Actions deploys the static export to GitHub Pages using `.github/workflows/static.yml` when changes are pushed to `main`.

# Pradheep C — Portfolio

A responsive React portfolio built with Vite. The site preserves the original dark OLED and neon orange visual identity and uses Tailwind CSS utilities with a small set of dedicated design-system styles.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Setup

```sh
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Commands

```sh
npm run build    # production build in dist/
npm run preview  # serve the production build locally
npm run lint     # ESLint checks
```

## Content and assets

Edit `src/data/personal.js`, `src/data/skills.js`, and `src/data/projects.js` to update portfolio content. Project URLs are intentionally empty until verified URLs are available. The resume link uses `public/resume/pradheep.pdf`. See [docs/PROJECT_STRUCTURE.md](docs/PROJECT_STRUCTURE.md) for architecture and form configuration.
